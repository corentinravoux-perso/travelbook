# Export fidelity spike (Task 1.2)

Throwaway. Answers design §10 "Fidelity gate". Outcome: `docs/decisions/0001-export-fidelity.md`.

## Run

```bash
cd spikes/export-fidelity
npm install                      # sharp + the two @fontsource packages (devDependencies of the spike only)
node gen-assets.mjs              # synthetic photos and stickers -> out/in/ (git-ignored, no personal photo)
# the shell may export ELECTRON_RUN_AS_NODE=1 (VS Code host): unset it
env -u ELECTRON_RUN_AS_NODE npx electron run.mjs --no-sandbox --prefer-css --variants   # PDF + one PDF per isolated effect
env -u ELECTRON_RUN_AS_NODE /usr/bin/time -v npx electron run.mjs --no-sandbox --prefer-css --dpi=300   # capture, max RSS
env -u ELECTRON_RUN_AS_NODE /usr/bin/time -v npx electron run.mjs --no-sandbox --prefer-css --dpi=600
node compare.mjs out/out-prefer-css.pdf out/out-300.png 300      # mean absolute pixel difference
python3 mm.py out/out*.pdf                                       # page size in mm versus 216 x 303
pdfimages -list out/out-prefer-css.pdf; pdffonts out/out-prefer-css.pdf
```

`run.mjs` page-size flags: none (CSS `@page` only), `--prefer-css`, `--inches` (explicit `pageSize`),
`--microns` (rejected by `printToPDF`, which takes inches). Outputs go to `out/` (git-ignored).

## Notes learned

- A plain hidden `BrowserWindow` never paints: `Page.captureScreenshot` hangs. The capture window is
  `offscreen: true`. `printToPDF` hangs in an offscreen window, so the PDF uses a separate plain hidden window.
- Without `app.on('window-all-closed')` handler, destroying a window quits the app mid-script.
